# Archived v5.0 qualification claims — withdrawn

This file previously contained numerical APCER/BPCER, physical attack, latency,
demographic, and independent-auditor claims. They were not supported by
reproducible current test evidence and are withdrawn. Do not cite the former
numbers, gate outcomes, cohorts, signatures, or ISO/IEC 30107-3 wording as
results or certification.

The current project supports only an experimental logged-in-user profile and
local comparison workflow. Its internal texture and blink code is not a
qualified anti-spoofing system. It is not connected to a supported face-unlock
path, and analysis errors must fail closed.

Use the [current v5.2.1 qualification status](RELEASE-QUALIFICATION-V5.2.md)
for the release boundary and remaining requirements. The
[v5.1.0 qualification status](RELEASE-QUALIFICATION-V5.1.md) is retained as a
historical development record. Required physical testing uses consent-based
presentation sets; report aggregate conditions and results only, and retain no
face images. Internal tests do not establish ISO/IEC 30107-3 certification.
